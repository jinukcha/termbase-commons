# Data licenses

Termbase Commons does not apply a single blanket license to every dataset.

Each termbase keeps the license of its source material.

## Current dataset

| Dataset | Source | Data license |
|---|---|---|
| LOINC Multilingual Termbase | LOINC 2.82 | LOINC License |

LOINC License: https://loinc.org/license/

## Rule

Project code may use MIT or Apache-2.0, but terminology data must always preserve the source license.
