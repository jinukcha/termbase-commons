# Licensing policy

## Repository code and templates

Use `LICENSE_CODE.md` for scripts and documentation templates.

## Data files

Each data file uses the license of its source material.

For LOINC-derived files, include:

```text
LOINC_short_license.txt
LOINC_LICENSE_FULL.txt
```

and link to:

```text
https://loinc.org/license/
```
